# BOX RUN — practical crank appearance study

Two built-in imagegen renders: the white printed device in use, and a front/open-back packaging study. These are concept images, not photographs of a working device or verified CAD.

User constraints: two-day build, white filament with paint available, red and yellow buttons, side crank, Pi Zero 2 W, 3.5-inch display, tape assembly and no screws.

The proposed crank uses a short printed arm and integral finger peg to avoid implying that a bearing/bolt assembly is already available. The actual encoder shaft, attachment and side-load support must be measured and prototyped. Tape closes panels; internal ledges/cradles must take button and encoder loads. The open-back view is illustrative and is not a wiring diagram, pin map or proven component arrangement.

No dimensions or printable enclosure files are supplied because display PCB, connectors, switch bodies, encoder and cable clearance have not been measured. Keep the whole case white, paint only the screen surround charcoal, and use the existing red/yellow buttons. The current request is visualization; these images do not implement the approved game concept.
