# Render round 2 — printable TICK concepts

These are appearance studies for the two-day build, not dimensioned CAD or verified printable assemblies. Built-in imagegen generated the renders; prompts are saved alongside them.

## The three shells

| Direction | Character | Build approach | Main tradeoff |
|---|---|---|---|
| Cream Cartridge | Warm, nostalgic, friendly | Cream shell, flat charcoal bezel, orange caps | Rounded shell needs care with print orientation |
| Graphite Terminal | Crypto terminal / test instrument | Dark shell, pale faceplate, lime accents | Fine ribbing can add print time; keep it shallow and optional |
| Orange Sandwich | Bold, visibly assembled, maker aesthetic | Flat front and rear plates around orange middle frame | Seams and screws are visible by design |

**Recommended for two days: Orange Sandwich.** Its flat separate color pieces make the fabrication process part of the look. Cream Cartridge is the gentler aesthetic alternative. Use colors already available; no multi-material printer is required if parts are printed separately and assembled.

All three retain two large left-thumb buttons and a right-side crank. The crank arm and grip can be printed, but the axle and fastening should use available hardware. Measure the actual encoder and provide support against side loads. Rendered screws, clearances, internal packaging and exploded views are illustrative. Print a shaft/clearance coupon before a full shell; choose tolerances from the actual printer result.

For camera: use contrasting crank grip and body, a broad matte face, strong screen contrast, and a front-right view. Avoid depending on paint, concealed snap fits or a folding mechanism for the deadline.

## Four game directions

These are alternatives to select from, not a four-game implementation commitment.

### BOX RUN — most directly about trading

Crank positions a target price range. A advances center → width → confirm. At expiry, the selected observed price either lands in the committed box or misses. A narrow target earns more practice points. Keep its meaning consistent: expiry price, not any intermediate touch. Render shows the aiming/round scene. Build one 20-second loop; label replay or simulation explicitly.

### BLOCK DROP — strongest pure arcade loop

A crane carries ETH-shaped cargo over a stack. Crank moves it left/right; A drops, B cancels before release. Overlap determines the next platform's width. Every few blocks the background advances to a new exchange district. Crypto is initially the theme; don't claim each block is an onchain transaction. This is likely the simplest route to satisfying play in two days: no external price behavior is needed to make it fun.

### GAS RUN — most crypto-native metaphor

Queue a courier's transaction crate for the next block. Crank selects one of three fee lanes; A sends. A higher fee spends more practice credits but moves the crate forward. Goal: meet the delivery deadline with the most credits left. Use a defined simulated queue initially; this is a fee-market puzzle, not a promise about actual network inclusion. Needs more tutorial work than BLOCK DROP.

### NERVE — strongest character moment

Crank sets round intensity, then A/B counterbalance a courier on a bridge while market-inspired gusts blow. Falling is a game outcome, not a real liquidation. Existing repo sketch can help, but the current browser rendering still needs a device port. Keep the world playful and the risk label honest.

## Selection

For a trading-led product: Orange Sandwich + BOX RUN.
For the most immediately enjoyable physical toy: Cream Cartridge + BLOCK DROP.
For the two-day deadline, choose one of those combinations and defer the remaining games. Prototype crank response and one complete win/loss cycle before spending time on decorative screens.
